theory Hoare

Hoare logic

Partial-correctness triples over the stream-of-states model of §11.6.

Constable et al. §11.6

Hoare logic over the streams-of-states model of `denotational.nuprl` (Constable et al. §11.6).

A Hoare triple `{P} s {Q}` means: from any initial state satisfying `P`, if the stream `s` has terminated by time `n`, then the store at that time satisfies `Q`. Skip, assignment, sequential composition with Skip, and the conditional are proved sound for this interpretation. Consequence is just implication of assertions.

-- | Hoare logic over the streams-of-states model of `denotational.nuprl`
-- (Constable et al. §11.6).
--
-- A Hoare triple `{P} s {Q}` means: from any initial state satisfying `P`,
-- if the stream `s` has terminated by time `n`, then the store at that time
-- satisfies `Q`. Skip, assignment, sequential composition with Skip, and
-- the conditional are proved sound for this interpretation. Consequence
-- is just implication of assertions.
theory Hoare

comment book "Hoare triples over the stream-of-states model, Constable et al. §11.6."

abs Fst(p) == let <u, v> = p in u
abs Snd(p) == let <u, v> = p in v
abs Store == Atom → Int
abs State == Store × (True ⊎ True)
abs Running(st) == <Fst(st), inl Ax>
abs Halted(st) == <Fst(st), inr Ax>
abs Terminated(st) ==
  decide (Snd(st)) of inl u => Void | inr u => True
abs StreamTy == State → Int → State

abs Abort == λa. λn. Running(a)
abs Skip == λa. λn. Halted(a)
abs Update(s; x; v) == λy. atom_eq y x v (s y)
abs Assign(x; v) == λa. λn. <Update(Fst(a); x; v), inr Ax>
abs Concat(s1; s2) ==
  λa. λn.
    decide (Snd(s1 a n)) of
      inl r => s1 a n
    | inr d => s2 (s1 a n) n
abs IF(r; s1; s2) ==
  λa. λn.
    decide (r (Fst(a))) of
      inl u => s1 a n
    | inr v => s2 a n

-- Partial correctness: P holds of the initial store, and if the stream
-- has halted by time n then Q holds of the store then.
abs Hoare(P; s; Q) ==
  ∀a:State. ∀n:Int.
    P (Fst(a)) → Terminated(s a n) → Q (Fst(s a n))

soft Fst, Snd, Store, State, Running, Halted, Terminated, StreamTy
soft Abort, Skip, Update, Assign, Concat, IF, Hoare
