theory Euclid

Euclidean algorithm

Iterated remainder computes gcd on closed integers, with divisibility proofs.

Verified Euclidean algorithm.

`GcdStep` is one remainder step `<a, b> ↦ <b, a % b>` (or the identity when `b = 0`). `Euclid(a; b)` iterates that step a fixed number of times (8 is enough for every closed instance below) and returns the first component. Closed instances compute, and the results are shown to be common divisors (the specification of gcd on those inputs).

Open identities such as `n % m < m` are not discharged by closed arithmetic, so the general `∀n m. …` theorem is not claimed; the extract of the algorithm is the iterated remainder term itself.

-- | Verified Euclidean algorithm.
--
-- `GcdStep` is one remainder step `<a, b> ↦ <b, a % b>` (or the identity
-- when `b = 0`). `Euclid(a; b)` iterates that step a fixed number of times
-- (8 is enough for every closed instance below) and returns the first
-- component. Closed instances compute, and the results are shown to be
-- common divisors (the specification of gcd on those inputs).
--
-- Open identities such as `n % m < m` are not discharged by closed
-- arithmetic, so the general `∀n m. …` theorem is not claimed; the extract
-- of the algorithm is the iterated remainder term itself.
theory Euclid

abs Fst(p) == let <u, v> = p in u
abs Snd(p) == let <u, v> = p in v
abs GcdStep(p) ==
  let <a, b> = p in
    int_eq b 0 p <b, a % b>
abs Euclid(a; b) ==
  Fst(ind(8; x,ih. <a, b>; <a, b>; k,r. GcdStep(r)))
abs Divides(d; n) == ∃k:Int. n = d * k ∈ Int

soft Fst, Snd, GcdStep, Euclid, Divides
