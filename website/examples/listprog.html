Lists as programs

Constable et al. §11.2

Lists as a programming theory, following Constable et al. §11.2 (the Nuprl book’s “Lists and Arrays”).

A discrete type has decidable equality; a predicate is decidable when it or its negation holds at every point. Head is defined in two ways (partial vs. defaulted), tail and length by `list_ind`, membership and non-repetition as recursively defined propositions, and a list fold is extracted from an existence theorem (Figure 11.3).

-- | Lists as a programming theory, following Constable et al. §11.2
-- (the Nuprl book’s “Lists and Arrays”).
--
-- A discrete type has decidable equality; a predicate is decidable when it
-- or its negation holds at every point. Head is defined in two ways (partial
-- vs. defaulted), tail and length by `list_ind`, membership and
-- non-repetition as recursively defined propositions, and a list fold is
-- extracted from an existence theorem (Figure 11.3).
theory ListProg

comment book "Constable et al. §11.2: lists and arrays as a programming theory."

abs Discrete(T) == ∀x:T. ∀y:T. x = y ∈ T ∨ ¬(x = y ∈ T)
abs Decidable(T; F) == ∀x:T. F x ∨ ¬(F x)
abs Hd(d; l) == list_ind l (d) (h, t, v. h)
abs Tl(l) == list_ind l ([]) (h, t, v. t)
abs Len(l) == list_ind l 0 (h, t, v. v + 1)
abs On(e; l; T) == list_ind l False (h, t, v. (e = h ∈ T) ∨ v)
abs Unique(l; T) == list_ind l True (h, t, v. ¬(On(h; t; T)) ∧ v)
abs Append(xs; ys) == list_ind xs (ys) (h, t, ih. h :: ih)
abs Sum(l) == list_ind l 0 (h, t, v. h + v)
abs Map(f; xs) == list_ind xs ([]) (h, t, ih. f h :: ih)

soft Discrete, Decidable, Hd, Tl, Len, On, Unique, Append, Sum, Map
