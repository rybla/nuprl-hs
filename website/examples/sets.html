theory Sets

Sets

Set types {x:A | P}: comprehension, empty/full/singleton, Nat, Positive, Bool.

Set types `{x:A | P}`: comprehension, carriers, and standard subsets.

An inhabitant of a set is an element of `A`; the proof of `P` is hidden (squash-like) and cannot appear in extracts. Independent intersection `A ∩ B` is *not* the set of common elements — that is `{x:A | x ∈ B}`.

-- | Set types `{x:A | P}`: comprehension, carriers, and standard subsets.
--
-- An inhabitant of a set is an element of `A`; the proof of `P` is hidden
-- (squash-like) and cannot appear in extracts. Independent intersection
-- `A ∩ B` is *not* the set of common elements — that is `{x:A | x ∈ B}`.
theory Sets

abs Empty(A) == {x:A | False}
abs Univ(A) == {x:A | True}
abs Singleton(A; a) == {x:A | x = a ∈ A}
abs Sep(A; F) == {x:A | F x}
abs Inter(A; F; G) == {x:A | F x ∧ G x}
abs Union(A; F; G) == {x:A | F x ∨ G x}
abs Subset(A; B) == ∀x:A. x ∈ B
abs Positive == {p:Int | 0 < p}
abs Nat == {n:Int | 0 ≤ n}
abs BoolZ == {x:Int | x = 0 ∈ Int ∨ x = 1 ∈ Int}

soft Empty, Univ, Singleton, Sep, Inter, Union, Subset, Positive, Nat, BoolZ
