theory Denotational

Denotational semantics

Streams of states; Abort, Skip, Assign, Concat, IF; depth-indexed syntax.

Constable et al. §11.6

Constructive denotational semantics of a small imperative language, following Constable et al., *Implementing Mathematics with the Nuprl Proof Development System* (1986), §11.6.

Meaning is a *stream of states*: given an initial state `a` and a time `n`, `s(a)(n)` is the program state after `n` steps. The domain `S` of well-formed streams is those functions that, once terminated, stay terminated (Figure 11.13). Combinators Abort, Skip, Assign, Concat and IF are the extracted objects of the book’s existence theorems; here they are written as terms and then shown to inhabit `S`.

The original library indexes statement syntax by a depth `N` using integer induction (`ind`), so that `Program = (d:N) × Statement(d)` without a recursive type (cf. Chapter 12, where the same grammar becomes `rec(T. Atomic | T#T | …)`). This file uses that `ind` encoding.

-- | Constructive denotational semantics of a small imperative language,
-- following Constable et al., *Implementing Mathematics with the Nuprl Proof
-- Development System* (1986), §11.6.
--
-- Meaning is a *stream of states*: given an initial state `a` and a time
-- `n`, `s(a)(n)` is the program state after `n` steps. The domain `S` of
-- well-formed streams is those functions that, once terminated, stay
-- terminated (Figure 11.13). Combinators Abort, Skip, Assign, Concat and
-- IF are the extracted objects of the book’s existence theorems; here they
-- are written as terms and then shown to inhabit `S`.
--
-- The original library indexes statement syntax by a depth `N` using
-- integer induction (`ind`), so that `Program = (d:N) × Statement(d)`
-- without a recursive type (cf. Chapter 12, where the same grammar becomes
-- `rec(T. Atomic | T#T | …)`). This file uses that `ind` encoding.

-- Projections, so spread is readable (the book’s `fst` / `1st` / `2nd`).

-- composition can pass the final store along (the book’s `State* | Done`
-- drops it at termination; the two encodings are otherwise the same).

abs Store == Atom → Int
abs State == Store × Status

-- run `s2` from that halted state for the remaining `n` ticks. This is the
-- book’s `decide` form of concatenation (Figure 11.13), with the residual

abs Concat(s1; s2) ==
  λa. λn.
    decide (Snd(s1 a n)) of
      inl r =&gt; s1 a n
