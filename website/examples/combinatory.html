theory Combinatory

Combinatory logic

SKI combinators and Church numerals, booleans, and pairs.

Combinatory logic and Church encodings.

The SKI basis is complete for the typed λ-calculus: `S`, `K`, and `I` inhabit the corresponding combinatory types, and `S K K` converts with `I`. Church numerals are the polymorphic iterators `⋂A:U{i}. (A → A) → A → A`; booleans are `⋂A:U{i}. A → A → A`. Evaluation at `Int` recovers the intended arithmetic.

-- | Combinatory logic and Church encodings.
--
-- The SKI basis is complete for the typed λ-calculus: `S`, `K`, and `I`
-- inhabit the corresponding combinatory types, and `S K K` converts with `I`.
-- Church numerals are the polymorphic iterators
-- `⋂A:U{i}. (A → A) → A → A`; booleans are `⋂A:U{i}. A → A → A`. Evaluation
-- at `Int` recovers the intended arithmetic.
theory Combinatory

abs I == λx. x
abs K == λx. λy. x
abs S == λf. λg. λx. (f x) (g x)
abs Bcomb == λf. λg. λx. f (g x)
abs CFlip == λf. λx. λy. f y x
abs W == λf. λx. f x x

-- Church numerals (polymorphic iterators).
abs CNat == ⋂A:U{i}. (A → A) → A → A
abs C0 == λs. λz. z
abs C1 == λs. λz. s z
abs C2 == λs. λz. s (s z)
abs C3 == λs. λz. s (s (s z))
abs CSucc == λn. λs. λz. s (n s z)
abs CPlus == λm. λn. λs. λz. m s (n s z)
abs CMult == λm. λn. λs. m (n s)
abs CToInt(n) == n (λx. x + 1) 0

-- Church booleans.
abs CBool == ⋂A:U{i}. A → A → A
abs CTrue == λt. λf. t
abs CFalse == λt. λf. f
abs CIf(b) == b
abs CAnd(p; q) == p q CFalse
abs COr(p; q) == p CTrue q
abs CNot(p) == p CFalse CTrue

-- Church pairs.
abs CPair(x; y) == λf. f x y
abs CFst(p) == p (λx. λy. x)
abs CSnd(p) == p (λx. λy. y)

soft I, K, S, Bcomb, CFlip, W
soft CNat, C0, C1, C2, C3, CSucc, CPlus, CMult, CToInt
soft CBool, CTrue, CFalse, CIf, CAnd, COr, CNot
soft CPair, CFst, CSnd
