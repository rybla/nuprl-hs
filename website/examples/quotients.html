Quotients

Quotient types (x,y):A // E. Integers mod 2; successor respects ≡, max does not.

Constable et al. §10.3

Quotient types, following Constable et al. §2.4 and §10.3.

`(x,y):A // E` has the members of `A`, but `a = b` holds when `E[a,b]` is inhabited. Formation requires `E` to be an equivalence relation. A function out of a quotient is well-defined only if it respects `E` (the successor on `ℤ/2ℤ` does; `max` does not).

-- | Quotient types, following Constable et al. §2.4 and §10.3.
--
-- `(x,y):A // E` has the members of `A`, but `a = b` holds when `E[a,b]`
-- is inhabited. Formation requires `E` to be an equivalence relation.
-- A function out of a quotient is well-defined only if it respects `E`
-- (the successor on `ℤ/2ℤ` does; `max` does not).
theory Quotients

-- Integers modulo 2: the book's `N2`.
abs EqMod2(x; y) == (x % 2) = (y % 2) ∈ Int
abs Z2 == (x, y):Int // EqMod2(x; y)
-- `max(a,b)` as a program on representatives (the book's counter-example).
abs Max(a; b) == less a b b a

soft EqMod2, Z2, Max

--------------------------------------------------------------------------------
-- The relation is an equivalence
--------------------------------------------------------------------------------

theorem eqmod2_refl :
  ∀x:Int. EqMod2(x; x)
proof
  intro x
  eq
qed

theorem eqmod2_sym :
  ∀x:Int. ∀y:Int. EqMod2(x; y) → EqMod2(y; x)
proof
  intro x
  intro y
  intro p
  elim 3
  eq
qed

theorem eqmod2_trans :
  ∀x:Int. ∀y:Int. ∀z:Int. EqMod2(x; y) → EqMod2(y; z) → EqMod2(x; z)
proof
  intro x
  intro y
  intro z
  intro p
  intro q
  elim 4
  hyp
qed

-- Formation: Z2 is a type
--------------------------------------------------------------------------------

theorem z2_type :
  Z2 ∈ U{i}
proof
  eq THENL [
    eq,
    eq THEN auto,
    eq,
    elim 3 THEN eq,
    elim 4 THEN hyp
  ]
qed
