Quotients

Quotient types (x,y):A // E. Integers mod 2; successor respects ≡, max does not.

Constable et al. §10.3

Quotient types and the functionality principle, following Constable et al. §2.4 and §10.3.

`(x,y):A // E` has the members of `A`, but `a = b` holds when `E[a,b]` is inhabited. Formation requires `E` to be an equivalence relation. A function on representatives is well-defined on the quotient if and only if it respects `E` (the functionality principle `quot_functionality`).

-- | Quotient types and the functionality principle, following Constable et al.
-- §2.4 and §10.3.
--
-- `(x,y):A // E` has the members of `A`, but `a = b` holds when `E[a,b]`
-- is inhabited. Formation requires `E` to be an equivalence relation.
-- A function on representatives is well-defined on the quotient if and only
-- if it respects `E` (the functionality principle `quot_functionality`).
theory Quotients

comment book "Constable et al. §2.4 & §10.3: quotient types, functionality, and equivalence relations."

-- Integers modulo 2: the book's `N2`.
abs EqMod2(x; y) == (x % 2) = (y % 2) ∈ Int
abs Z2 == (x, y):Int // EqMod2(x; y)

-- `max(a,b)` as a program on representatives (the book's counterexample).
abs Max(a; b) == less a b b a

soft EqMod2, Z2, Max
