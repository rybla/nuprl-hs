theory Choice

Axiom of choice

Type-theoretic AC is a theorem: a total relation yields a choice function.

The constructive axiom of choice.

In computational type theory, choice is a *theorem*, not an extra axiom. A proof of `∀x:A. ∃y:B. R x y` *is* a function that, for each `x`, returns a pair `<y, p>` with `p : R x y`. Projecting yields a choice function `f x = y` together with a proof that `R x (f x)` (Martin-Löf; NuPRL §2.3). The extract is that projection.

Classical AC (from `∀x. [∃y. R x y]`) is not constructive: the squash hides the witness, so no function can be extracted. Unique choice from a squash needs a uniqueness proof and is not derived here.

-- | The constructive axiom of choice.
--
-- In computational type theory, choice is a *theorem*, not an extra axiom.
-- A proof of `∀x:A. ∃y:B. R x y` *is* a function that, for each `x`, returns
-- a pair `<y, p>` with `p : R x y`. Projecting yields a choice function
-- `f x = y` together with a proof that `R x (f x)` (Martin-Löf; NuPRL §2.3).
-- The extract is that projection.
--
-- Classical AC (from `∀x. [∃y. R x y]`) is not constructive: the squash
-- hides the witness, so no function can be extracted. Unique choice from a
-- squash needs a uniqueness proof and is not derived here.
theory Choice

abs Fst(p) == let <u, v> = p in u
abs Snd(p) == let <u, v> = p in v

soft Fst, Snd

  intro x
  intro y
  auto
qed
